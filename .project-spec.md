# AI-Assisted Student Success & Placement Readiness System
## Full Project Specification

### Tech Stack
- **Frontend:** React 18 + Vite + Tailwind CSS + React Router v6 + Zustand
- **Backend:** Node.js + Express.js + Prisma ORM
- **Database:** SQLite (dev) → PostgreSQL (prod) via Prisma
- **AI/ML:** Google Gemini API (gemini-1.5-flash) for mock interviews, analysis, recommendations
- **Auth:** JWT + bcrypt, Role-Based Access Control
- **File Upload:** Multer
- **Validation:** Zod
- **API:** RESTful JSON APIs

### Roles
- **Student:** Dashboard, Tests, My Analysis, Mock Interview, Recommended Jobs, Placement Drives, Profile
- **Placement Officer:** Drive Management, Eligibility Management, Application Tracking, Company Assessment, Results & Shortlisting, Company Feedback
- **Company:** Submit requirements, request assessments, view authorized reports
- **Admin:** User management, Question banks, Career/skill mappings, Learning resources

### Core Modules
1. Auth & RBAC (JWT)
2. Student Profile & Career Goal
3. Assessment Engine (timed tests, MCQ, coding)
4. My Analysis (Readiness Score, Skill Gaps, Recommendations)
5. AI Mock Interview (Gemini API)
6. Job Recommendation Engine
7. Campus Placement Drives
8. Placement Officer Portal
9. Company Portal
10. Admin Portal

### AI Components (via Gemini API)
- Placement Readiness Score (weighted multi-factor)
- Skill Gap Detection (vs benchmark vectors)
- Learning Recommendations (content-based filtering)
- Mock Interview Q&A (LLM with rubric prompts)
- Job Matching (cosine similarity + ranking)
- Diagnostic Feedback (NLP generation)
