# Ascend: AI-Assisted Student Placement Readiness & Institutional Intelligence System
## Full Technical Specification

### 1. Technology Stack
- **Frontend:** React 19 + Vite 8 + Tailwind CSS v3 + React Router v7 + Zustand + Lucide Icons + Axios
- **Backend:** Java 21 LTS + Spring Boot 3.3.4 (RESTful Web Services)
- **Persistence & ORM:** PostgreSQL 16 + Spring Data JPA / Hibernate + Flyway Database Migrations
- **AI & NLP Intelligence:** Google Gemini API (`gemini-3.5-flash-lite` / `gemini-1.5-flash`) with turn-by-turn prompt engineering and multi-tiered fallback banks
- **Authentication & Security:** Stateless JWT (HMAC-SHA256) + Spring Security 6 + Role-Based Access Control (RBAC) + Email OTP verification
- **Communication & Notifications:** Spring Mail (JavaMailSender) + Centralized SMTP Gateway + Audit Logging

### 3. Role-Based Portals & Access Control
- **Student Portal (`/student/*`):** Profile management, career target selection, timed diagnostic assessments, Test Review with shuffled answers, 4-pillar placement readiness analysis, turn-by-turn AI mock interviews, live job recommendations with direct links, and placement drive applications.
- **Placement Officer Portal (`/officer/*`):** Drive creation with strict eligibility gates (CGPA, department, backlogs), applicant pipeline management (APPLIED → ASSESSMENT → SHORTLISTED → SELECTED), review of public recruiter opportunities, and recruitment analytics.
- **Corporate Recruiter Portal (`/company/*`):** Hiring requisition management, candidate assessment tracking, applicant report review, and candidate evaluation feedback.
- **System Administrator Portal (`/admin/*`):** User management, question bank curation across 13 technical & aptitude categories, external recruiter intake review, and email audit logs.
- **Public Recruiter Intake (`/api/public/opportunities`):** Unauthenticated portal for corporate hiring partners to submit recruitment opportunities with automated tracking ID generation.

### 4. Dynamic AI Capabilities
- **4-Pillar Dynamic Readiness Model:** Synthesizes Technical Assessments (45%), AI Mock Interviews (25%), Academic Standing (15%), and Profile Readiness (15%) to prevent artificial single-test score leaps.
- **Adaptive Mock Interviews:** Turn-by-turn Gemini-powered technical evaluation stepping from Easy warm-up definition questions up to architectural scale and trade-offs, backed by comprehensive fallback question banks.
- **Diagnostic Explainable Analysis:** Mathematical deficit ranking (`Deficit = Benchmark - Observed`) paired with contextual remediation roadmaps.
